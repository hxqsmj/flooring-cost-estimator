# 工业地坪造价估算器

单文件、零依赖的工业地坪**包工包料造价**估算工具。输入面积、地坪体系、基层状况和区域类型，得出参考总价区间、材料/人工拆分和预估工期。

在线使用：https://hxqsmj.github.io/flooring-cost-estimator/

配套的**材料用量**计算器：[flooring-calculator](https://github.com/hxqsmj/flooring-calculator)

## 支持的地坪体系

| 体系 | 参考单价（元/㎡，包工包料） |
|---|---|
| 环氧薄涂 0.5-1mm | 25 - 35 |
| 环氧砂浆 2-3mm | 45 - 70 |
| 环氧自流平 2-3mm | 25 - 60 |
| 防静电环氧 2-3mm | 60 - 120 |
| 聚氨酯砂浆 6-9mm | 90 - 150 |
| 金刚砂耐磨 3-5mm | 25 - 45 |
| 混凝土密封固化剂 | 15 - 25 |
| 地下车库地坪（含标线） | 35 - 70 |

> 以上是长三角地区实际施工的**参考区间**，不是固定报价。同一材料在不同现场可能落在区间两端，差异主要来自基层处理、厚度、施工条件和区域洁净要求。

## 计算逻辑

```
综合单价 = 基础单价 × 基层系数 × 区域系数
总造价   = 综合单价 × 面积
```

- **基层系数**：新地面 1.0 / 需铣刨打磨 1.12 / 有破损需修补 1.25 / 起砂严重 1.4
- **区域系数**：普通生产区 1.0 / 洁净要求 1.08 / 车辆通行 1.06 / 潮湿冲洗区 1.1

## 免责说明

这是一个**估算工具**，输出的是区间而非报价。实际价格需要现场勘测才能确定，因为以下因素无法通过网页判断：基层强度与含水率、平整度、是否需要做防潮层、施工季节与工期要求、材料品牌选择。
